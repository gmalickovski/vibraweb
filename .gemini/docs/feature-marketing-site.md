# Marketing Site

**Page**: `src/pages/SitePage.tsx`  
**Components**: `src/components/site/`

## Sections

| Component      | Description                                    |
|----------------|------------------------------------------------|
| `SiteHeader`   | Sticky glassmorphism header with nav + CTA     |
| `Hero`         | Full-bleed hero with wine glow + headline      |
| `Analyses`     | 4-column grid of analysis types                |
| `Features`     | 2-column feature list with gradient bar accent |
| `Pricing`      | Essencial (free) + Pro (R$79/mês) cards        |
| `FAQ`          | Accordion with 5 questions                     |
| `SiteFooter`   | Logo mark + copyright                          |

## Copy Language

Portuguese (pt-BR). Tone: warm, professional, slightly mystical but grounded.

## CTAs

All CTAs call `onEnter` → navigate to `LoginPage`.

## Pricing

- **Cadastro inicial**: 7 dias de teste gratuito para todos os perfis.
- **Plano Inicial / Essencial**: Uso da plataforma para análises e geração de mapa completo com a marca e marca d'água do Vibraweb.
- **Plano Premium / Pro**: Tudo do plano inicial + possibilidade de retirar a marca do Vibraweb e personalizar o documento com sua própria logomarca, cores, além de funcionalidades adicionais de análise.
